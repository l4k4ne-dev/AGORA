# ⚠️ AGORA — WORK IN PROGRESS — NOT E2E

This repository is the reference implementation of the Agora protocol.
**As of 2026-07-22, the current build does NOT implement end-to-end encryption.**

The Python cryptographic modules (X3DH, Double Ratchet) exist and are tested,
but are NOT connected to the Flutter client flow. Current mobile builds
transmit and store messages in plaintext.

**Do not use this build for any communication requiring privacy.**

Rebuild in progress. See `docs/STATUS.md` and the Agora Whitepaper v0.1 for
the target architecture.
